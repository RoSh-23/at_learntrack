# LEARNTRACK - STUDENT COURSE MANGEMENT SYSTEM

## Description
* It is a system that allows users to add, search and edit student, courses and associated enrollments.
* Currently this is an in-memory implementation of this system.

## How to Compile & Run
* Go to the repo folder and ensure you are inside "src" folder
* Linux complie: javac -d bin $(find src -name "*.java")
* Linux Run: Compile: java -cp bin com.airtribe.learntrack.Main
